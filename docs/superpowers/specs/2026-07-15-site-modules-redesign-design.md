# qizh.space 模块重构设计(2026-07-15)

本轮范围:**/prompt、/tool、palm 分享卡、全站导航互链**。play 不动;主页/about/writing/post 仅记录建议、本轮不改(见文末)。

## 决策(已与用户确认)
- /prompt 服务对象 = ADHD 用户本人;机制 = AI 一键改写(复用 palm 的智谱免费直连 + 页面内 key)。
- palm 分享 = 图片卡为主 + 文案兜底。
- /tool 新增 4 个:二维码生成、图片压缩/格式转换、Markdown→公众号排版、复利/杠杆计算器(原 7 个保留)。
- 顺带做导航互链(最高 ROI)。
- key 暴露风险沿用 palm 现状(免费额度可接受);Worker 代理不可行(*.workers.dev 国内被墙),暂不处理。

## ① /prompt —「乱麻模式」ADHD 极速 Prompt 生成器
- 主界面:单个大 textarea(占位"把脑子里乱糟糟的需求丢进来,不用管顺序")+ 大按钮「✨ 变成完美 Prompt」。零选择、零启动阻力。
- 生成:把口水话喂 glm-4v-flash(纯文本调用),meta-prompt 让其输出结构完整、可直接粘贴的高质量 prompt(自动补角色/格式/约束/示例)。直连 bigmodel.cn,GLM_KEY 复用 palm 同一个。
- ADHD 能力:
  - 场景预设 chips(点一下即填入乱麻框并可直接生成):把邮件写礼貌 / 把这段总结成 3 句 / 把待办拆成步骤 / 我不知道怎么开头帮我起个头。
  - 「任务拆解」开关:生成的 prompt 让 AI 把大任务切成"5 分钟能开始的第一步"。
  - 结果下方「还不够好?再狠一点 →」= 一键再优化(把上次结果再喂一轮)。
- 灵动:chips 即点即用;生成中 loading;结果单块 + 一键复制,不给第二个决策点;结果卡底部水印 `qizh.space/prompt · 微信搜 Zion降噪`。
- 保留原精选库(质量高),挪到下方 + 加即时搜索过滤。
- 失败兜底:API 挂/无 key → 回退到"结构化模板拼接"(现有构建器逻辑),不白屏。

## ② /tool — 实用工具聚合站
- 落地页改为**可搜索卡片墙**:顶部搜索框(按工具名/别名即时过滤),下面按分类铺卡片:文本·写作 / 图片 / 换算·计算 / 编码·开发。一行"最近用过"(localStorage,最多 4 个)。
- 点卡片进入工具(沿用现有 hash 深链 + 输入→一键→输出→复制范式)。开发类(JSON/Base64/URL/正则/时间戳)归到"编码·开发"、默认折叠降权;人民币大写、字数统计保留。
- 新增 4 个(纯前端、无后端):
  - 二维码生成器(纯 JS,支持文本/URL,可下载 PNG)。
  - 图片压缩/格式转换(canvas → JPEG/WebP + 改尺寸 + 显示前后体积)。
  - Markdown→公众号排版(MD 解析 → 内联样式富文本,可复制粘进公众号后台)。
  - 复利/杠杆计算器(本金/月投/年化/年限 → 终值 + 收益,结果可复制)。
- 撤掉工具页的 AdSense(与"零广告"文案冲突且拖慢秒开)。

## ③ palm 分享卡
- canvas 画一张竖版分享海报:人设标签 + 综合分 + 四维 + 一句毒舌钩子 + "微信搜 Zion降噪 回复手相" + `qizh.space/palm` 水印,金黑配色。
- 「甩给最该看的人」→ 生成图片:`navigator.share` 支持文件时直接分享图片;否则展示图片 + "长按保存"提示。保留纯文案+链接作兜底(复制)。

## ④ 导航互链(全站)
- 统一子导航片段:工具 / Prompt / 手相 / 游戏 / 主站,铺进 index、tool、prompt、palm、play(play 至少加"← 主站"角标)。
- 主页 nav 增 `工具` 入口;footer 补 Tools / Prompt / Palm。
